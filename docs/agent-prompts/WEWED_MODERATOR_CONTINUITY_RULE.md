# WEWED MODERATOR CONTINUITY RULE

Status: **AUTHORITATIVE MODERATOR OPERATING RULE**

Purpose: prevent Wewed programme stalls between moderator review and the next progressive agent unit.

## Core rule

The moderator is not finished when a returned agent unit has merely been classified.

Every moderator cycle must end in one of two states:

### A. Next progressive agent is released

The moderator must immediately:

1. classify the returned work;
2. perform any authorized ordinary closure;
3. determine the next progressive unit from the authoritative plan;
4. create/update the repository task file;
5. send the full next-agent prompt;
6. keep later phases explicitly parked/frozen.

### B. External blocker prevents the next progressive execution

The moderator must still create and send a blocker-resolution prompt that names:

- the exact unavailable input/authority;
- the authorized source of that input;
- the secure handoff route;
- the exact resumption point;
- forbidden actions;
- the completion line that returns control to the moderator.

The moderator must never terminate a cycle with only a verdict, status report, or suggestion.

## Required programme chain

`implementation/research/certification agent`
→ `moderator independent review`
→ `moderator closure where authorized`
→ **`next task + prompt issued immediately`**
→ `next agent`.

## Prohibited moderator endings

Unless the owner explicitly pauses the programme, do not end with only:

- “accepted”;
- “partially accepted”;
- “blocked”;
- “not proven”;
- “next step is …”;
- “send me X when ready”;
- “want me to prepare the next task?”

The prompt must already be prepared and issued.

## Relationship to safety gates

Continuity does not permit skipping gates.

A follow-up prompt may be:

- an implementation task;
- an independent certification task;
- an environment-enablement task;
- a secure credential-input task;
- a blocker investigation task;
- an owner-decision preparation task.

It must preserve the authoritative phase order and all production/data safety freezes.

## Source format

All released tasks use:

`docs/agent-prompts/WEWED_MODERATOR_AGENT_PROMPT_FORMAT.md`

This rule applies to all future Wewed moderator sessions unless the owner explicitly supersedes it.
