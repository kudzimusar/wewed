# Wewed Planner Alpha Daily Workflow

This workflow is the tester-facing path through the active wedding. Always confirm the selected wedding in the context control before making a change.

## 1. Plan in the workspace

Start in **Planning workspace**. Use Overview to scan task progress, budget exposure, confirmed guests, and vendor readiness. Then work in the six operational modules:

- Tasks: create, filter, assign, update status, and remove work.
- Budget: maintain estimates, actuals, payments, due dates, and category totals.
- Vendors: maintain contact, contract, payment, rating, notes, and pipeline data.
- Guests: maintain contact and RSVP readiness, filter the list, and assign tables.
- Timeline: create, edit, reorder, print, and remove run-sheet items.
- Seating: create and resize tables, assign or unassign parties, and resolve capacity warnings.

Use the worksheet recovery panel for an explicit template download, import preview, field mapping, export, history review, or rollback. Opening the planner never imports or seeds data automatically.

## 2. Coordinate in Team Hub

Open **Team Hub** to review assigned work and overdue items, maintain the vendor pipeline, request or decide approvals, share document links, discuss wedding-scoped records, and clear notifications.

## 3. Update the client profile

Open **Client profile** when the couple, wedding date, venue, public-site wording, images, features, or location details change. Saving updates only the selected wedding and its public website data.

## 4. Run daily operations

Open **Daily Ops** to review readiness and priority work, preview or send RSVP reminders, apply or save reusable planning templates, preview or apply capacity-safe auto-seating, and inspect import history.

Use **RSVP Links** when invitation links need to be repaired and exported for distribution.

## 5. Execute the wedding day

Open **Wedding Day** for live check-in, table status, run-sheet progress, readiness, and issue management. The command centre refreshes while open and remains scoped to the selected wedding.

## Switching weddings safely

Before switching weddings, save or discard drafts when prompted. A successful switch remounts the planning workspace and the unified tool navigation for the newly selected wedding. Recheck the wedding title, date, venue, and role before continuing.

## End-of-day close

Review overdue tasks, pending approvals, failed reminders, import errors, unseated confirmed parties, outstanding payments, and open wedding-day issues. Export or record anything required for the next planner handoff.
