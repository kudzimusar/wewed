# Notebook live transcription security boundary

The browser captures microphone audio only after explicit consent. The original WebM is uploaded to Wewed private Notebook storage. Short PCM-derived WAV chunks are sent only to authenticated Wewed Notebook routes; those server routes call the configured private speech-to-text provider. Z.AI/Groq credentials are never returned in readiness responses or embedded in client code. Transcript output remains editable Notebook source material and does not approve any financial or contractual action.
